# Java Job Recruitment Portal

## Project Overview
A console-based Job Recruitment Portal developed using Core Java. This project simulates a basic HR screening process where candidate details are collected and evaluated based on predefined recruitment criteria.

## Features
- Collect candidate personal details.
- Check graduation eligibility.
- Evaluate work experience.
- Verify programming language knowledge.
- Check OOP and SQL knowledge.
- Evaluate Java project experience.
- Verify expected salary against company budget.
- Check relocation availability.
- Evaluate joining availability.
- Display the final selection or rejection result.

## Technologies Used
- Java
- Scanner Class
- Conditional Statements
- Nested If-Else
- Methods

## Recruitment Workflow
1. Candidate enters personal details.
2. Graduation eligibility is checked.
3. Work experience is evaluated.
4. Technical skills are assessed.
5. Expected salary is verified.
6. Relocation availability is checked.
7. Joining availability is evaluated.
8. Final recruitment decision is displayed.

## How to Run
1. Clone this repository.
2. Open the project in Eclipse or another Java IDE.
3. Locate `JobPortal.java`.
4. Run the program.
5. Enter candidate details in the console.
